# Design

## Visual world

Trilha Redes uses an operative cyberpunk classroom aesthetic: near-black blue ground, electric cyan for active network flow, magenta for team identity, and acid yellow for countdown urgency. It is a real game dashboard first—controls remain ordinary, labelled web controls.

## Typography and density

Condensed display lettering gives the board and turn announcement a game-like presence; legible sans-serif copy carries questions and controls. The board is a compact numbered route with conspicuous category markers.

## Signature move

The board is a compact, serpentine minimap rather than a cell grid: numbered category nodes sit on a luminous route, peões gather below their node, and the active node pulses softly. Motion respects reduced-motion settings.

## Components

Outlined panels, square-ish 12px corners, thin luminous dividers, category chips, numbered token buttons, and semantic status colors are shared throughout the game flow.
